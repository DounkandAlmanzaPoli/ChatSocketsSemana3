# ChatSocketsSemana3

Esta versión permite enviar mensajes a cualquier usuario conectado, cambiando el destinatario en cada envío. No se bloquea al usuario en una conversación exclusiva.

## Importar en NetBeans 21
1. Descomprime el ZIP.
2. Abre NetBeans 21.
3. File > Open Project.
4. Selecciona la carpeta que contiene `pom.xml`.
5. Ejecuta `ChatServer.java` con clic derecho > Run File.
6. Pulsa Iniciar servidor en la ventana del servidor.
7. Ejecuta `ChatClient.java` varias veces para abrir varias ventanas cliente.
